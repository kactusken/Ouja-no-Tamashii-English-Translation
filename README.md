# Zen Nippon Pro Wrestling: Ouja no Tamashii - English translation

This repository holds the tools and the translation data (text tables, image transcriptions and
English). **No disc image, game files or artwork are included.** To play the translation, download
the patches from the [Releases](../../releases) page and apply them to your own copy of the original
Japanese disc. To build or change it yourself, see [Building it yourself](#building-it-yourself).

## Playing the translation

### 1. The original disc image

The patches need the Redump dump of the Japanese release, as a single-track BIN/CUE:

| | |
|---|---|
| File | `Zen Nihon Pro Wres - Ouja no Tamashii (Japan).bin` |
| Size | 498,751,008 bytes |
| CRC32 | `8ae69263` |
| SHA-1 | `1bc41b753496de3487538a68bbf49714001d7f03` |

If your copy is a CHD, convert it back to BIN/CUE first with MAME's chdman:
```sh
chdman extractcd -i "game.chd" -o "game.cue"
```

### 2. Pick a patch

Each release's `.zip` holds three patches. Each one is applied to the **original** image on its own -
don't apply one on top of another (the translation moves data around the disc, so a second patch
would land on the wrong bytes).

| Patch | What you get |
|---|---|
| `… (English).xdelta` | the translation only |
| `… (English + Unlocks).xdelta` | the translation with every unlock below |
| `… (Japan + Unlocks).xdelta` | the original Japanese game with every unlock below |

Unlocks:
- **Survival Match** (and Title Match) on the mode select from the start - normally impossible to unlock.
- **Edit Wrestler**: every body, move set, logic and entrance type open from the start (normally gated
  by clearing Path of the Five Crowns chapters), and the hidden bodies 44-50 at the end of the Body
  Type list.
- **Path of the Five Crowns**: the full wrestler lists in both chapters (normally a button code).

### 3. Apply it

| Platform | Patcher |
|---|---|
| Windows | [Delta Patcher](https://github.com/marco-calautti/DeltaPatcher): *Original file* = the Japanese `.bin`, *XDelta patch* = the `.xdelta` file |
| Android | UniPatcher |
| Any browser | [Rom Patcher JS](https://www.marcrobledo.com/RomPatcher.js/) |
| Command line | `xdelta3 -d -s "<Japanese .bin>" "<patch>.xdelta" "<output>.bin"` |

Save the patched image under the patch's name with `.bin` instead of `.xdelta`, and put the matching
`.cue` file from the release next to it - the `.cue` refers to the `.bin` by name. Open the `.cue` in
your emulator. The `README.txt` in each release lists the checksums of the patched images, so you can
check that patching worked.

## Building it yourself

### Where everything is

```
Ouja-no-Tamashii-English-Translation/
├── original-game/        the Japanese disc image you provide (.bin + .cue)
├── translation/          ← EVERYTHING YOU EDIT
│   ├── text/             in-game text tables: PROG.csv, STAFF.csv (credits), CRW.csv
│   ├── graphics.csv      every image with Japanese text: transcription, English, status, notes
│   ├── glossary.md       wrestler names and terms
│   ├── images-handmade/  your hand-edited images (always win at build time; not in git)
│   └── images-approved/  reviewed images, frozen (not in git)
├── output/               ← THE TRANSLATED GAME: load the .cue in an emulator
├── review/               ← THINGS TO LOOK AT (regenerated by the tools)
│   ├── images-japanese/  every original image
│   ├── images-english/   every final English image, exactly as in the last build
│   ├── compare/          side-by-side Japanese | English sheets
│   ├── contact-sheets/   sheets of the original images
│   └── edit/             reference images from edit.py
├── tools/                the scripts (all folder paths are defined in tools/paths.py)
├── docs/                 EDITING.md (how to edit images), NOTES.md (technical notes)
└── cache/                internal working files - safe to delete
```

Game data and art stay out of git: `original-game/`, `output/`, `review/`, `cache/`,
`translation/images-approved/`, `translation/images-handmade/` and image/art files (`*.png`, `*.psd`,
`*.act`) are all ignored.

#### Folder locations

The layout above is the default, relative to the project folder. Every tool that uses these folders
accepts options to move them (relative paths are taken from the current directory):

| Option | Default | |
|---|---|---|
| `--root DIR` | the project folder | base for every default below |
| `--original PATH` | `original-game/` | the Japanese `.bin`, or a folder holding it |
| `--translation DIR` | `translation/` | text tables, `graphics.csv`, hand-made and approved images |
| `--output DIR` | `output/` | the translated disc image |
| `--review DIR` | `review/` | regenerated pictures to look at |
| `--cache DIR` | `cache/` | internal working files |

For example, with the disc somewhere else and the result written next to it:
```sh
.venv/bin/python tools/build.py --original ~/games/zen-nihon/ --output ~/games/zen-nihon/english
```

### Setup (once)

1. Put `Zen Nihon Pro Wres - Ouja no Tamashii (Japan).bin` and `.cue` (Redump,
   SHA-1 `1bc41b753496de3487538a68bbf49714001d7f03`) in `original-game/` (or point `--original` at it).
2. Create the Python environment:
   ```sh
   python3 -m venv .venv && .venv/bin/pip install capstone pillow
   ```
3. Build once - this also extracts everything the other tools need:
   ```sh
   .venv/bin/python tools/build.py
   ```

### Everyday use

| I want to… | Do this |
|---|---|
| Play the translation | load `output/Zen Nihon Pro Wres - Ouja no Tamashii (English).cue` |
| Change in-game text | edit the `english` column in `translation/text/*.csv`, then build |
| Change the English of an image | edit `english` (or `font`/`align`/`boxes`) in `translation/graphics.csv`, then `.venv/bin/python tools/render.py --regen <image>` |
| Redraw an image by hand | see [docs/EDITING.md](docs/EDITING.md) |
| See every image Japanese vs English | `.venv/bin/python tools/compare.py` → `review/compare/` |
| Find an image | `.venv/bin/python tools/edit.py list <words>` |
| Rebuild the game | `.venv/bin/python tools/build.py` |

**Text tables**: each row's `max_bytes` is a guide; the build relocates longer strings and stores
English as full-width characters (the game can't draw plain ASCII). Credits are re-laid out
automatically (`tools/staff_layout.py`).

**graphics.csv**: `status`: `done` (translated; the image is a frozen file in `images-approved/`, copied
as-is by every build - nothing is redrawn), `keep` (stays Japanese), `todo` (new / unfinished). After
changing a row, `render.py --regen <image>[,<image>…]` re-renders and re-freezes it and writes a
before/after picture to `review/edit/<image>_regen.png`. Rows with `dup_of` (status `dup`) are exact copies
of another image and follow it. Optional columns: `font` (large-bold / large / medium-bold / medium /
tiny), `align` (left / center / quote), `boxes` (per-label boxes for composite images, `x,y,w,h;...`),
`review` (notes from reviewing the result), and `' / '` in the English forces a line break.
Small labels that need a uniform look the renderer can't learn from the original art (e.g. the match
finish labels 0707_035-061) are drawn directly in the shared style and frozen in `images-approved/`.

**Build**: `tools/build.py` verifies the original, inserts text, renders/imports graphics and writes
`output/…(English).bin/.cue`. It also applies gameplay patches (`CODE_PATCHES` in build.py, details in docs/NOTES.md):
**Survival Match** (and Title Match) on the mode select from the start - normally impossible to unlock;
**Edit Wrestler** with every body, move set, logic and entrance type open (normally gated by clearing Five
Crowns chapters); the hidden bodies 44-50 (track-suit Inoue / Asako / Shiga / Kanemaru, Takeshi
Morishima, track-suit Mossman, referee Kyohei Wada) at the end of the Body Type list, or via the
original trick: hold SELECT while confirming the Body page on Baba, Taue, Inoue, Asako, Shiga, Kanemaru
or Mossman; and the **full Path of the Five Crowns rosters** - normally a button code adds Fuchi, Ogawa,
Tsuruta and Baba to Succession and Kanemaru, Kikuchi and Asako to Ascent.
`--unlocks` picks them: `all` (default), `none`, or some of `survival`, `edit`, `crowns` (e.g.
`--unlocks survival,crowns`).
Test builds: `--boot staff` (or `prog` / `enter` / `match` / `crw`) starts straight in that part of the
game, e.g. the credits; `--no-translation` skips text and graphics, and gameplay patches unless
`--unlocks` is given - on its own the result is byte-identical to the original, and with `--boot` it
makes a Japanese control build.

**Release**: `tools/release.py --version v1.0` builds every variant (English, English + Unlocks, Japan +
Unlocks), makes an xdelta3 patch of each against the original, checks that each patch reproduces its
build, and writes `output/release/Zen-Translation-v1.0/` (patches, `.cue` files, README.txt with
checksums) and a `.zip` of it. Each patch applies to the clean original on its own - they can't be
stacked, because the translation moves PROG.BIN and regenerates sector EDC/ECC. Needs `xdelta3`
(`apt install xdelta3`).

## Tools

| Tool | Purpose |
|---|---|
| `tools/build.py` | full build |
| `tools/release.py` | release patches (xdelta3) for every variant |
| `tools/edit.py` | set up / check / approve hand-edited images, write reference images |
| `tools/sheet.py` | `edit.py sheet …`: edit several images as one sheet |
| `tools/compare.py` | side-by-side Japanese / English sheets |
| `tools/menu_buttons.py` | main-menu buttons in the hand-made style (needs DejaVu Sans Bold, or `--font`) |
| `tools/render.py`, `fonts.py`, `styled.py` | automatic English rendering of images |
| `tools/text.py`, `staff_layout.py` | text insertion, credit layout |
| `tools/disc.py`, `arc.py`, `bpe.py`, `gfx.py` | disc image, archives, compression, image formats |
| `tools/mips.py`, `ramscan.py` | reverse-engineering helpers |
| `tools/bodytex.py` | export wrestler body textures → `review/body-textures/` |
| `tools/paths.py` | every folder location in one place, and the folder options |

Technical notes (file formats, memory layout, how text is drawn): [docs/NOTES.md](docs/NOTES.md).
